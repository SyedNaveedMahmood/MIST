# MIST-Sleep — Morphology-Awareness Analysis

Scientific evaluation of the central project risk (RESEARCH_CRITIQUE.md #1):
**does MAE pre-training make the MRCNN encoder morphology-aware — i.e. does it
represent / reconstruct sleep spindles (11-16 Hz), K-complexes and slow waves —
or does raw-MSE reconstruction collapse onto low-frequency 1/f power and ignore
the diagnostically critical transient morphology? Does band-weighting fix it?**

Author: analyst pass over the Checkpoint-2 `morphology/` harness. CPU, torch 2.12.
All numbers below are from synthetic labelled EEG (no real EDF yet — see Gaps).

---

## 0. TL;DR verdict

| Sub-question | Verdict | Confidence |
|---|---|---|
| Does **raw-MSE** MAE learn spindle morphology? | **No.** It loses ~100% of spindle-band energy (power_ratio 0.000) and reconstructs *no* band well in a fair budget. | High (synthetic) |
| Does **band-weighting** recover morphology? | **Partially yes** for *reconstruction* — spindle energy recovers to ~30% and every band's spectral error drops 3x. | High (synthetic) |
| Is **linear-probe decodability** different between variants? | **No — within noise**, and the difference vs a *random untrained encoder* and a *raw band-power baseline* is also within noise. | High |
| Is the probe a valid morphology test as built? | **No — it is confounded** by raw signal energy in the pooled features. A random encoder and a 5-number FFT band-power vector match or beat the trained encoders. | High |

**Bottom line:** the *reconstruction* evidence supports the critique and supports
band-weighting as the default. The *probe* evidence, as currently constructed,
supports **nothing** about MAE — it must be fixed before it can back the
"morphology-aware" claim. The headline "morphology-aware encoder" claim is **not
yet defensible**; it is defensible only as "band-weighted MAE reconstructs
spindle-band morphology that raw MSE discards."

## 1. Harness audit (scientific validity) and fixes applied

I audited every harness component before trusting any number.

### 1.1 Synthetic generator (`synthetic_eeg.py`) — adequate, one caveat
- 1/f background is generated by amplitude-shaping white noise with
  `1/f^(exponent/2)`, so **power ∝ 1/f^exponent = 1/f^1.0** by default. Real scalp
  EEG aperiodic slope is steeper (power ≈ 1/f^1.5–2.5). A *gentler* slope is a
  **conservative** choice: it under-stacks low-frequency power against the spindle
  band, so it makes the spectral-bias failure *harder* to observe, not easier.
  The failure still appears strongly → the finding is robust to this. Noted, not
  changed (changing it would only sharpen the result).
- Event SNR: spindle amplitude 0.4–0.9 × background std, Gaussian-tapered — a
  realistic, deliberately *low* SNR (spindles sit below delta power). Good.
- Prevalence: spindle p=0.8, K-complex p=0.6, slow-wave p=0.7 → base rates
  ~0.75 / 0.59 / 0.70 (confirmed in run logs). High base rates are the right
  regime to expose the probe-confound below (a majority-class predictor already
  scores ~0.75 on spindle).

### 1.2 Band metrics (`band_metrics.py`) — measure what they claim, verified
- Sigma band isolation = (11.0, 16.0) Hz everywhere (BANDS, BAND_RANGES,
  `spindle_band_fidelity` default) — consistent across generator, loss and metric.
- Mask restriction: `band_resolved_recon_error(mask=...)` zeroes the *unmasked*
  region of **both** recon and target before the FFT, so it scores only the
  reconstructed (hidden) region for both variants identically. Correct & fair.
- `spindle_band_fidelity` further restricts to the **intersection of masked and
  spindle regions** (`mask & spindle_mask`) — exactly "spindle-band fidelity on
  masked spindle regions". Correct.
- Sensitivity caveat (documented, not a bug): the *relative* spectral error
  saturates near 1.0 when a variant reconstructs almost nothing in the masked
  block (true of raw MSE here), so it compresses differences *among bad models*.
  The **`power_ratio`** metric (recon in-band power / target in-band power) is the
  more discriminating spectral-bias diagnostic and is the one to read for the
  spindle verdict.

### 1.3 Linear probe (`probes.py`) — frozen & non-leaking, but CONFOUNDED
- Frozen encoder: `extract_embeddings` is under `@torch.no_grad()` and the probe
  is a *separate* `nn.Linear` trained only on the pooled features — no gradient
  reaches the encoder. No train/test leakage (split indices are disjoint;
  standardisation stats are taken from train only). Mechanically clean. ✔
- **Confound (the important finding):** the probe decodes from `feat.mean(-1)`
  of the MRCNN map. Mean-pooled conv features of a *random* or *untrained* encoder
  still linearly expose **band energy** of the input. So a high probe accuracy can
  reflect *raw signal energy*, not anything MAE learned. The original harness had
  **no control** for this. I added two:
  1. **Random-encoder probe** — same MRCNN, untrained.
  2. **Raw-bandpower probe** — decode presence from the 5 log band-powers of the
     raw signal (no encoder at all).
  If trained-MAE probes don't beat these, the probe says nothing about MAE.

### 1.4 Matched-conditions audit — fixed
- raw / freq / band variants share identical data, epochs, lr, optimizer, model
  capacity, and **identical reconstruction masks at eval** (`torch.manual_seed(
  12345)` before `reconstruct`), differing *only* in `loss_mode`. Verified. ✔
- The Checkpoint-2 orchestrator only ran raw vs band; the mandate asks for
  raw vs **freq** vs band. The new `morphology/run_analysis.py` runs all three
  plus the two controls, across multiple seeds, with mean±std.

### 1.5 Code fixes committed
- `model/mae.py::concentrated_mask` — replaced the per-sample Python `for` loop
  with a vectorised contiguous-block mask (same output; verified identical mask
  ratio 0.75, contiguity, and length). Pure speed/correctness hygiene; lets the
  multi-seed experiment run on CPU.
- Added `morphology/run_analysis.py` — the rigorous multi-seed runner with the
  random-encoder and raw-bandpower **probe controls** and a presence/absence
  framing, emitting JSON + mean±std tables.

## 2. Experiment

- Data: synthetic labelled EEG, 30 s @ 100 Hz. Train = 400 epochs/seed,
  test = 250 epochs/seed (held-out, generated with a disjoint seed offset +1000).
- Variants (matched but for the loss):
  - **raw** — masked time-domain MSE (proposal default; suspected biased).
  - **freq** — raw MSE + flat magnitude-spectrum MSE (`freq_weight=0.1`).
  - **band** — masked MSE + band-weighted magnitude-spectrum MSE, sigma×10,
    beta×3, alpha×2.
- Controls: **random_enc** (untrained MRCNN probe), **raw_bandpower** (FFT band
  energies → linear probe, no encoder).
- Training: 20 epochs (2× the builder's 10; convergence checked against a 3-epoch
  point — see §3.4), Adam lr 1e-3, mask ratio 0.75.
- Seeds: 0, 1, 2 → mean ± std. (Scaled from the builder's single-seed/10-epoch/
  400-sample preliminary run. CPU compute on this 4-core box is the limiting
  factor; the wide-kernel MRCNN conv dominates, ~3 s/epoch.)
- Reproduce: `python -m morphology.run_analysis --n_train 400 --n_test 250
  --epochs 20 --seeds 0 1 2 --json_out results/morph_analysis.json`
  (raw JSON in `results/morph_analysis.json`, gitignored).

## 3. Results (mean ± std over 3 seeds)

### 3.1 Band-resolved RELATIVE reconstruction error (lower = better)

```
  band            raw              freq             band
  delta     0.933 +/- 0.008   0.887 +/- 0.007   0.303 +/- 0.011
  theta     0.976 +/- 0.004   0.937 +/- 0.001   0.278 +/- 0.002
  alpha     0.981 +/- 0.003   0.949 +/- 0.002   0.280 +/- 0.005
  sigma     0.985 +/- 0.003   0.958 +/- 0.002   0.294 +/- 0.004   <- spindle band
  beta      0.987 +/- 0.002   0.963 +/- 0.002   0.441 +/- 0.031
```

Reading:
- **raw MSE reconstructs essentially nothing** in a fair budget — every band sits
  at 0.93–0.99 relative error, i.e. the recon contributes almost no correct
  spectral content in the masked block. Note the *gradient*: delta (0.933) is the
  least-bad band and sigma/beta (0.985/0.987) the worst — the **low-frequency
  preference predicted by the critique is visible** even though everything is bad.
- **freq** helps marginally and uniformly (~0.03–0.05), not enough.
- **band-weighting transforms it**: all bands drop to ~0.28–0.44 relative error,
  a ~3x improvement, with the sigma (spindle) band at 0.294 — now *among the
  best-reconstructed*, exactly the intended inversion of the bias.

### 3.2 Spindle-band (11-16 Hz) fidelity on masked spindle regions

```
  metric          raw              freq             band
  corr        0.018 +/- 0.014  -0.002 +/- 0.006   0.000 +/- 0.010
  rel_err     0.984 +/- 0.001   0.947 +/- 0.005   0.949 +/- 0.004
  power_ratio 0.000 +/- 0.000   0.002 +/- 0.001   0.302 +/- 0.037   <- key
```

Reading (`power_ratio` = recon spindle power / target spindle power; 1.0 ideal):
- **raw MSE = 0.000**: it discards ~100% of spindle-band energy on masked spindle
  regions. This is the clean, unambiguous confirmation of the spectral-bias
  failure mode — the single most important number in this report.
- **freq = 0.002**: a flat spectral term barely moves it.
- **band = 0.302 ± 0.037**: band-weighting recovers ~30% of spindle energy —
  large and consistent across seeds (std 0.037), i.e. real signal not noise.
- Caveat: waveform-level `corr` is ~0 for all variants and `rel_err` stays high
  even for band — at 20 epochs the model recovers spindle *energy/envelope* but
  not phase-accurate waveform. So "morphology-aware" here means **band-power /
  presence**, not waveform reconstruction. Honest scope.

### 3.3 Frozen-encoder linear-probe decodability (accuracy, with controls)

```
  event        raw            freq           band         random_enc    raw_bandpower
  spindle  0.760 +/- 0.022  0.760 +/- 0.061  0.773 +/- 0.082  0.738 +/- 0.054  0.804 +/- 0.064
  kcomplex 0.600 +/- 0.044  0.609 +/- 0.017  0.631 +/- 0.056  0.556 +/- 0.023  0.582 +/- 0.017
  slowwave 0.853 +/- 0.039  0.862 +/- 0.033  0.840 +/- 0.019  0.862 +/- 0.017  0.884 +/- 0.017
```

Reading — this is where the original harness would have over-claimed:
- **raw vs freq vs band are statistically indistinguishable** for every event
  (all overlap within 1 std; e.g. spindle 0.760/0.760/0.773). With this power,
  there is **no probe evidence that band-weighting improves decodability**.
- **The trained encoders do not beat the RANDOM encoder**: spindle 0.760 (raw)
  vs 0.738 (random) — overlapping. K-complex trained encoders edge the random one
  (0.60–0.63 vs 0.556) but within ~1 std. MAE pre-training adds **no clear linear
  decodability** over an untrained MRCNN.
- **A 5-number raw band-power vector matches or beats all encoders**: spindle
  0.804, slow-wave 0.884 — i.e. presence is decodable straight from input FFT
  energy, *no encoder required*. This is the confound made explicit.
- Conclusion: as built, **the probe measures input signal energy, not learned
  morphology**. Its near-equality across variants is not evidence of "both are
  morphology-aware" — it is evidence the probe is **uninformative** here.

### 3.4 Convergence sanity (is 20 epochs past noise?)
At 3 epochs (single seed) the band-resolved errors were ~0.98 (sigma) for raw and
~0.98 for band, and spindle power_ratio was raw 0.000 / band ~0.002 — i.e. the
**band advantage had not yet appeared**. By 20 epochs the band variant has clearly
separated (sigma rel 0.294, power_ratio 0.302) while raw stays flat. So the
reconstruction conclusion is a *converged-trend* result, not a few-step artefact.
Raw MSE shows no sign of catching up — its loss is dominated by the visible-region
passthrough and the low-frequency bulk, consistent with the bias hypothesis.

## 4. Critical judgment (answers, with confounds)

**Q1. Does raw-MSE MAE learn morphology?**
No (high confidence, synthetic). It reconstructs no band well and loses ~all
spindle energy (power_ratio 0.000). The relative-error gradient (delta best, sigma
worst) shows the predicted low-frequency preference. The probe cannot rescue this
claim because the probe is confounded (Q4).

**Q2. Does band-weighting recover it?**
For reconstruction, yes and substantially (high confidence): 3x lower band errors
and 30% spindle-energy recovery, stable across seeds. For *waveform* fidelity,
only partially — energy/envelope yes, phase-accurate waveform no at this budget.
For *decodability*, no measurable gain (Q3).

**Q3. Is probe decodability actually different once you have power?**
No. raw/freq/band overlap within noise on all three events at n=250×3 seeds.
There is no statistical basis to claim band-weighting improves linear
decodability. (It improves *reconstruction*, which is a different, and here the
only supported, axis of "morphology-awareness".)

**Q4. Confounds.**
The dominant confound is exactly the one the mandate flagged: **the probe can
decode from raw signal energy rather than encoder features.** Proven directly —
(a) a random untrained MRCNN matches the trained encoders, and (b) a 5-number FFT
band-power baseline (no encoder) matches or beats them. Mean-pooling over the conv
feature map preserves band energy, so presence is trivially linearly readable
regardless of training. Until the probe is made to *exceed* these controls, probe
accuracy is not admissible as morphology-awareness evidence. I added both controls
to the harness so this can never be silently over-claimed again.

Secondary confound: high event base rates (~0.75 spindle) inflate raw accuracy;
macro-F1 (already reported in JSON) and a balanced presence/absence sampling are
the right reads, and I report the controls on the same footing so the comparison
is apples-to-apples.

## 5. Recommendations (prioritized)

**P0 — make the MAE morphology-targeting by default.**
- Set the Stage-1 default `mae_loss_mode = "band"` (sigma up-weighted), not
  "raw". The reconstruction evidence is unambiguous: raw MSE discards the spindle
  band. Keep raw as an *ablation* (A2-raw) to demonstrate the failure, but do not
  ship it as the representation learner.
- Sigma weight: ×10 worked well here (sigma rel 0.294, power_ratio 0.302). Sweep
  {3, 10, 30}; watch that beta does not over-dominate (its error 0.441 is the
  worst of the band variant — the broad sigma+beta up-weighting slightly starves
  beta; consider sigma-only or a gentler beta weight). Add a sigma-only config.
- Strongly consider moving to a **spectrogram / STFT reconstruction target**
  (LaBraM-style), which directly optimizes time-frequency morphology and would
  also fix the waveform-`corr`≈0 limitation; the band-weighted magnitude term is
  a cheaper stand-in that already proves the point.

**P0 — fix the probe protocol before any morphology claim.**
- Report probe accuracy **relative to the random-encoder and raw-bandpower
  controls** (now in `run_analysis.py`). The defensible claim is "encoder probe
  *minus* control", and it must be positive with non-overlapping std.
- The current mean-pool leaks band energy. Make the probe harder to satisfy
  trivially: (a) probe from the encoder's *learned* representation in a way the
  band-power baseline cannot mimic (e.g. localize spindle *timing* / count, not
  just presence); (b) use a difficulty-matched negative set; (c) report macro-F1
  and balanced accuracy, not raw accuracy on a 0.75-prevalence label.
- Add an **event-localization** probe (predict per-window spindle mask) — far less
  decodable from global band energy, so it actually tests morphology in the latent.

**P1 — strengthen the evaluation protocol.**
- Steeper 1/f (power 1/f^1.5–2.0) as the default generator slope, to match real
  EEG and make the test more stressful; the finding should only sharpen.
- More epochs / data for a final figure (this run was CPU-bounded at 20 epochs,
  3 seeds, 400/250 samples; the trend is clear but a 50-epoch, 5-seed run would
  tighten the bands). Cache encoders so probes can be re-run without retraining.
- Add `power_ratio` per band (not just sigma) to the standard table — it is the
  most discriminating spectral-bias diagnostic; the relative-error metric
  saturates for bad models.

**P1 — validate on real EDF spindle annotations.**
- The whole report is synthetic. Before the "morphology-aware" claim ships, run
  band-resolved recon error + spindle-localization probe on **real EDF epochs
  with expert spindle/K-complex annotations** (e.g. MASS SS2 has spindle scoring;
  Sleep-EDF has limited event marks). Synthetic proves the *mechanism*; real data
  proves the *claim*.

**P2 — reporting hygiene.**
- Whenever "morphology-aware" is asserted, cite the **reconstruction** evidence
  (band error + spindle power_ratio), not probe accuracy, until the probe clears
  its controls.

## 6. Honest gaps / limitations
- Synthetic only; no real EDF event annotations yet (P1 above).
- 20 epochs / 400 train / 3 seeds — CPU-limited; trend is converged for
  reconstruction but probe estimates have wide std (the controls overlap, which is
  itself the finding).
- Band variant recovers spindle *energy/envelope*, not phase-accurate waveform
  (`corr`≈0); a spectrogram target is the path to true waveform morphology.
- `freq` mode's spectral term is computed over the whole signal (incl. the visible
  passthrough region), a mild asymmetry vs the mask-restricted band term; freq is
  a weak secondary variant and this does not affect the raw-vs-band verdict.
